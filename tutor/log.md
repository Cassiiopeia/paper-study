# 튜터 로그

세션마다 조수가 적는다. **무엇을 시도했고, 사용자가 뭐라고 했고, 어떻게 판단했나.**
증거는 사용자의 말을 그대로 인용한다 — 조수의 느낌이 아니라.
판단은 셋 중 하나: **○ 효과** / **✗ 버림** / **? 더 볼 것**.
같은 시도가 두 번 ○ 면 `playbook.md` 「검증됨」으로 올린다. ✗ 는 즉시 「버린 것」으로.
