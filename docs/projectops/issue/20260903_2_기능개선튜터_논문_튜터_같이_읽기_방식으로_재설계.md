📝 현재 문제점
---

- 현재 튜터 규칙은 "요약 금지, 쪽 번호만 제시, 답해야 다음 구간"이라 사용자가 논문을 혼자 읽고 조수는 채점만 하는 구조다. 읽기 전에 시험지부터 받는 셈이라 읽을 동기가 떨어진다.
- 한 번에 여러 쪽과 질문 여러 개를 한꺼번에 주면 시작조차 못 한다. 실제 세션에서 확인된 문제다.
- 틀린 답에 쪽 번호만 주고 무엇이 틀렸는지 말하지 않아, 고친 내용을 반영해 다시 쓰는 반복 학습이 되지 않는다.
- 원문이 스캔본이라 세션마다 이미지를 렌더링해 읽어야 하고, 키워드와 힌트를 뽑을 텍스트가 없다.
- 어떤 가르침 방식이 이 사용자에게 효과 있었는지 기록이 없어 세션마다 같은 실수를 반복할 수 있다.

🛠️ 해결 방안 / 제안 기능
---

- **덩어리(문단~소절) 단위 "같이 읽기" 루프**: 키워드 3~5개와 힌트 한 줄 → 사용자가 읽고 답 → 질문(요약형, 키워드형, 왜형, 조립형, 기법형) → 조수가 틀린 곳과 빠진 조각을 직접 짚음 → 사용자가 다시 씀 → 통과할 때까지 반복(최대 3회). 빈 답이면 힌트 단계를 올린다(키워드 → 문장 위치 → 문장 앞 절반 → 같이 읽기).
- **세션 내 반복**: 덩어리 2~3개마다 앞 내용을 되묻는다. 장이 끝나면 본인 말 3문장을 설명 대본에 조립한다.
- **원문 텍스트 추출**: 스캔 PDF를 쪽 단위 마크다운으로 옮겨 적고, 쪽 메타데이터(절 제목, 표/그림 유무, 키워드, 튜터 힌트)를 머리말에 둔다. 평문은 gitignore, vault로 봉한 `.enc`만 커밋한다. 이후 세션은 이미지 대신 텍스트를 읽는다.
- **튜터 플레이북과 로그**: 세션마다 시도한 방식과 사용자 반응을 기록하고, 두 번 이상 효과 본 방식만 플레이북으로 승격해 다음 세션에 적용한다. 효과 없던 방식은 "버린 것"으로 남겨 다시 쓰지 않는다.
- **기록 틀 개편**: 세션 기록에 1차 답, 피드백, 2차 답을 원문 그대로 남기고, 설명 대본에 장별 내 말 요약 칸을 추가한다.

유지하는 것: 큰 줄기(1차) → 세부(2차) → 비판(3차) → 설명 시험 순서, 카드와 복습 간격, 답 원문 그대로 기록, 세션 끝 커밋, 사용자 부담 0.
