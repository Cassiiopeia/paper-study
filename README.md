# paper-study

논문을 **읽고 끝내지 않기 위한** 저장소.

요약을 받아 읽는 것이 아니라 답을 해야 다음이 열리고, 답한 것은 카드가 되어
며칠 뒤·몇 주 뒤에 다시 돌아온다. 목표는 "읽었다" 가 아니라
**"누가 물어도 설명할 수 있다"** 이다.

## 어떻게 도는가

```
        ┌─ 1차 뼈대 ──→ 2차 논증 ──→ 3차 비판 ──→ 설명 시험 ─┐
        │   초록·결론     장마다        한계·내 프로젝트   5분 발표  │
        │                한 세션                          + 꼬리질문│
        └──────────── 매 구간마다 카드 2~4장 ──────────────┘
                              ↓
                    1일 → 3일 → 7일 → 21일 → 60일
                    (틀리면 처음으로)
```

세션을 열면 **복습 카드부터** 나온다. 그걸 마쳐야 새 구간이 열린다.
이게 기록만 쌓이고 기억은 안 남는 흔한 실패를 막는 장치다.

## 규칙 넷

1. **요약 금지** — 조수는 내용을 먼저 말하지 않는다. "몇 쪽 어느 문단" 까지만
2. **통행세** — 직전 구간에 답해야 다음이 열린다. 틀린 답은 통과, **빈 답만 되돌린다**
3. **15~20분치씩** — 한 세션에 한 장(章) 이하
4. **본인 말로 3문장** — 용어 없이 설명 못 하면 그 구간은 안 읽힌 것

그리고 **사용자 부담은 0** 이다. 채팅에서 답만 하면 된다 —
기록·카드·복습 일정·커밋은 전부 조수가 한다.

전체 규칙은 [CLAUDE.md](CLAUDE.md) 에 있고, 조수가 세션마다 읽는다.

## 구조

```
CLAUDE.md              튜터 규칙 — 이 저장소의 설계 그 자체
progress.md            어느 논문 몇 차 어디까지
papers/                원문 — 봉함본(.enc)만 커밋된다
notes/<슬러그>/
  00-meta.md           서지 · 진행 차수 · 쪽 색인
  01-sessions.md       세션 로그. 내가 답한 문장 그대로
  02-defense.md        예상 질문 ○/✗. 발표 전날 ✗만 본다
  03-my-project.md     이 논문이 내 프로젝트 어디에 걸리나
  04-explain.md        5분 설명 대본 — 최종 관문
knowledge/
  cards.md             인출 카드 + 복습 일정
  issues.md            쟁점 지도 — 논문이 쌓일수록 값어치가 커진다
  concepts.md          용어 사전 (보조)
scripts/
  review.py            복습 큐
  vault.py             원문 봉하기 / 열기
```

## 도구

```bash
python scripts/review.py due                       # 오늘 물어야 할 카드
python scripts/review.py grade <id> o|t|x          # 맞음 / 반만 / 틀림
python scripts/review.py stats                     # 몇 장이 살아있나

python scripts/vault.py unseal                     # .enc -> 평문 PDF (읽기 전)
python scripts/vault.py seal                       # 평문 -> .enc (커밋 전)
```

## 원문 다루기

저장소가 공개되어 있어 원문 PDF 를 평문으로 두지 않는다.
`papers/*.pdf` 는 gitignore 되고 **AES-256-GCM 으로 봉한 `.enc` 만** 올라간다.

키는 환경변수 `PAPER_STUDY_KEY`(base64 32바이트), 없으면 `.key` 파일에서 읽는다.
**둘 다 gitignore 대상이고 키 값은 어디에도 적지 않는다.** `keygen` 은 키를 화면에 찍지 않는다.
nonce 를 원문에서 결정론적으로 뽑으므로 같은 PDF 는 다시 봉해도 암호문이 같다 — 불필요한 diff 가 없다.

> base64 는 암호화가 아니다. 키 없이 되돌아가므로 원문을 그냥 올린 것과 같고, 저작권도
> 그것으로는 풀리지 않는다. 원문 저작권이 걱정되면 `papers/` 를 통째로 gitignore 하는 편이 깨끗하다.
